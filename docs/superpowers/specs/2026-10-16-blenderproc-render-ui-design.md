# BlenderProc 本地渲染 UI 设计

日期：2026-10-16

状态：设计草案，待用户确认；尚未开始产品实现。

## 1. 用途与已确认的需求

这个项目帮助用户通过界面配置合成训练数据的生成策略，减少学习 BlenderProc API、编写采样脚本和调整遮挡物摆放的工作量。

用户已经明确：

- 在 Ubuntu 22.04 使用本地 UI，生成脚本后自行在终端运行。
- 现有 BlenderProc 环境是 conda 的 `bop`。
- 提供目标 PLY、遮挡物模型和 Haven 一类的背景资源。
- 最终只需 BOP 数据；YOLO 标签转换由用户处理。
- 设置相机随机采样范围、光照强度和遮挡比例。
- 相机范围以物体为球心，通过类似球坐标的数值限定；有时只生成几个方向的数据。
- 界面应接近 Blender 本身的布局和视觉风格。

原脚本实际使用 Haven HDRI 环境，因此本设计把背景明确为 HDRI 环境图。它提供背景和环境照明，不要求导入三维房间或地面模型。

## 2. 第一版的范围

### 必须交付

1. 可运行的本地桌面应用，中文界面。
2. 目标模型、遮挡物集合、HDRI 环境目录的选择与校验。
3. 真实目标网格的交互式三维预览，以及相机球坐标范围和采样点的几何示意。
4. 相机、光照、遮挡、生成数量、BOP 输出等配置的保存和重新载入。
5. 生成独立的 BlenderProc 渲染任务目录，含脚本、配置、辅助模块和运行说明。
6. 用户可复制的终端命令，以及少量试渲染所需的命令参数。
7. 实际渲染输出符合约定的 BOP 结构，并记录采样结果和未达标原因。

### 第一版不包含

- YOLO 检测框、分割标签转换和训练。
- 在 UI 中启动、停止或管理渲染进程；远程队列、Web 服务及云端部署。
- 嵌入 Blender 编辑器、建模、材质节点编辑和物理堆叠仿真。
- UI 内的 Cycles 实时渲染或对最终 HDRI/阴影效果的准确预览。
- 三维背景模型、背景图片后期粘贴、多类别或多目标实例同场景。
- 第一版自动更改目标的随机姿态；方向多样性由相机区域表达。

**以上版本范围是设计者的取舍，需随本设计一起由用户确认。** 单个项目选择一个目标网格和一个 BOP 对象 ID；可以保存多个项目来分别生成不同目标的数据。

- BlenderProc 实际使用本机 Blender 4.2.1，内部 Python 是 3.11；conda 中的包不等于 Blender 内部可导入的包。
- 原脚本已有相机/点光源采样、Haven HDRI 和 BOP 写出；遮挡率仅通过摆放高度近似。

三维预览使用可嵌入 Qt 的 OpenGL 视图组件。具体视图库及其版本由实施计划根据 Ubuntu 22.04 和本机验证结果选定；必须能显示目标网格、坐标轴、球面区域、相机点，并支持旋转、平移和缩放。

## 4. 界面与交互

参考草图：`.superpowers/brainstorm/130178-1792153482/content/blender-hdri-layout.html`。这是布局参考，不是已经实现的应用，也不是所有示例数值的确认。

- 顶部使用紧凑菜单和“场景 / 采样 / 脚本”工作区标签。
- 中央为灰色三维视口，选中目标使用橙色轮廓或明确的橙色选择标记。
- 右上显示目标、遮挡物、相机、点光源、World/HDRI 的对象树。
- 右下是窄的属性类别栏与可折叠参数面板，数字输入和间距接近 Blender。
- 底部显示少量相机采样位置示意或终端命令；状态栏显示当前项目状态和计划数量。
- 允许调整区域分隔宽度；1024×768 窗口仍可操作，属性面板独立滚动。

**场景工作区：** 选文件、模型单位、BOP 对象 ID、遮挡物列表、HDRI 列表和环境设置。选择目标后自动调整观察视图以看清模型。

**采样工作区：** 相机区域管理、球坐标范围、样本数量、光照、遮挡和高级相机设置。编辑范围后即更新几何示意；预览相机的观察方向与最终生成相机范围是独立的，拖动视口不修改采样配置。

**脚本工作区：** 选择导出目录、BOP 输出目录、环境名和依赖路径，查看校验结果、导出内容和完整运行命令。按钮表达为“导出脚本与配置”，不暗示渲染已完成。

真实 RGB、阴影和背景效果通过终端小样本渲染检查。辅助网格、坐标轴、采样区域和相机图标不出现在渲染结果中。

## 5. 输入资源与坐标

### 目标与遮挡物

- 目标首要支持有可渲染面的 PLY 网格；仅有点的 PLY 给出明确提示，不当作完整表面渲染。
- 遮挡物首版支持 PLY、OBJ 网格，可选择多个文件或扫描目录，过滤无关文件。
- 目标和遮挡物分别指定 m / cm / mm，导入后展示换算后的尺寸。所有场景距离配置以米计。
- 保留目标的原始模型坐标和原点。相机球心取目标局部包围盒中心，经目标变换得到世界坐标；不通过改写模型顶点来重新定义 BOP 原点。
- 默认将目标包围盒中心放到世界原点，导入旋转保持不变；这通过对象变换完成，并准确记录 BOP 位姿。
- 优先保留已有材质/顶点颜色；没有可用颜色时提供中性材质。复杂材质编辑留在 Blender 中完成。

### HDRI 环境

- 支持选择单个 `.hdr` / `.exr` 或递归扫描 Haven 资源目录，并列出可用环境图。
- 可固定一张环境图，或从启用的列表随机选择。
- 配置环境强度范围和绕世界 Z 轴的旋转角度范围。
- HDRI 不提供放置物体的几何表面；默认不额外生成房间或地面。
- 本地文件不存在、目录没有匹配资源或格式无法载入时，在导出前明确指出具体资源。

## 6. 相机球坐标区域

每个区域包含唯一 ID、可编辑名称，以及距离 r、方位角 φ、仰角 α 的范围。

定义采用目标的局部坐标轴：

- 球心 c 为目标局部包围盒中心的世界位置。
- r 是相机到球心的距离，单位米，必须大于 0。
- φ = 0° 沿目标局部 +X，向 +Y 增大。
- α = 0° 位于局部 XY 平面，+90° 沿局部 +Z，−90° 沿局部 −Z。
- 相机默认始终看向 c，不随机滚转。

设 R 为目标局部旋转到世界坐标的旋转矩阵，则相机位置为：

`p = c + R · [r cos(α) cos(φ), r cos(α) sin(φ), r sin(α)]`

实现规则：

1. r 上下限相同表示固定距离；角度上下限相同表示固定角度。三者全固定是合法固定机位。
2. φ 对用户统一使用 `[-180°, 180°]`。`170° → −170°` 表示跨边界的 20° 区域。整周使用单独的“全方位”选项，避免与固定角度混淆。
3. α 位于 `[-90°, 90°]`，下限不得大于上限；极点处采用稳定的相机上方向，避免退化或翻转。
4. 默认 r 在距离区间内均匀，φ 在角区间内均匀，`sin(α)` 在对应区间内均匀，使方向在球面区域内均匀。
5. 区域随目标的平移和旋转变化，不使用与目标脱离的世界方位。
6. 支持添加、命名、复制和删除区域，至少保留一个。默认各区域均分总样本数，余数按稳定顺序分配。
7. 区域重叠会提高重叠方向的出现频率；界面提示这一点。样本数少于区域数时提示部分区域没有样本。
8. 预览显示内外距离边界、角度边界、轴标签与若干采样相机点；当前区域突出显示。
9. 导入后的初始距离根据目标尺寸和相机视场角给出建议，用户可覆盖。实际渲染检查目标完整入画和相机未进入模型。

分辨率默认沿用现有 `640×480`；默认内参沿用现有配置：`fx=572.4114, fy=573.57043, cx=325.2611, cy=242.04899`。高级设置允许编辑 K；按比例修改分辨率时默认同步缩放内参，手动内参模式需明确标识。

## 7. 光照与遮挡自动策略

### 光照

- 使用一个点光源，界面设置功率范围；位置默认在目标上方半球采样，合理初始距离按目标尺寸给出。
- 点光源位置、颜色/冷暖范围归入高级设置。
- HDRI 环境强度独立于点光源功率，分别保存和随机采样。
- 每个实际图像对应的相机、灯光、环境和遮挡物状态必须一致。批量渲染时显式绑定帧或分批次执行，不能把最后一次灯光状态误用于所有图像。

### 遮挡

界面核心参数为“无遮挡样本比例”和“其余样本的遮挡率范围”。遮挡物数量、缩放、摆放容差和重试上限放在高级设置。

**设计者的选择：** 遮挡率按实际像素验收，不沿用原脚本的摆放强度近似。固定相机和目标，分别显示、隐藏指定遮挡物，测量当前画面内的目标实例像素：

`occlusion = 1 − visible_target_pixels / target_pixels_without_occluders`

- 目标自身遮挡不计入额外遮挡；baseline 的目标像素数必须大于 0。
- 目标完整入画单独检查，默认不接受裁切样本，不把出画面积当作遮挡。
- 使用低采样实例分割进行验收，不做两次完整 RGB 渲染；最终验收分辨率与输出分辨率一致。
- 自动在相机与目标之间选择、缩放和摆放遮挡物，排除相机与模型相交、遮挡物与目标穿插等无效候选。
- 未达范围时重新采样；不会把不达标样本静默计为成功。
- 建议初始值：无遮挡 20%，其余遮挡 10%–50%，每个请求样本最多尝试 30 次。这些是设计者的初始值，可在 UI 修改。
- 达到重试上限后记录失败并继续其他请求，最终明确报告实际完成数和未完成数；未全部完成时返回非零退出状态。

BOP 的 `visib_fract` 和上述验收遮挡率保留为不同字段，不把它们强行等同。BOP 的画幅外计数和可见性深度容差遵循原生 writer 行为。

## 8. 配置、导出与终端运行

项目配置使用带 `schema_version` 的 YAML，包含资源路径、单位、目标 ID、相机内参和区域、采样数、光照/HDRI、遮挡策略、随机种子、渲染质量、运行环境与输出位置。保存后重新载入必须完整恢复设置；缺失字段按版本迁移或给出可操作错误。

导出的任务目录至少包含：

```text
render_job/
  render_scene.py
  scene.yaml
  runtime/             # 任务需要的辅助代码，可按实施情况拆分
  README.txt
```

用户资源默认保留在原位置，导出配置使用解析后的本机绝对路径；不默认复制大型模型或 HDRI，也不自动改写原项目。

终端运行示例：

```bash
conda activate bop
blenderproc run render_scene.py --config scene.yaml
```

提供生成可正确引用含空格路径的完整命令，并提供少量试渲染覆盖参数（例如 `--num-samples 5 --output <新目录>`）。关闭 UI 后导出的任务仍能运行，也不要求从原仓库目录执行。

运行前检查 BlenderProc、模型、HDRI、BOP toolkit、输出目录及实际 Blender Python 依赖。BOP toolkit 可配置本机路径；不在渲染中静默联网安装缺失依赖。缺失时在运行说明中提供明确处理步骤。

随机种子和实际采样参数写入日志。相同资源、版本和配置应能重现相同的相机/资源选择序列；不承诺跨设备 Cycles RGB 完全逐像素一致。

## 9. BOP 输出与文件保护

输出具有明确的数据集名称，包含标准场景图像、深度、实例掩码、相机与位姿标注：

```text
<output>/<dataset_name>/
  models/
    obj_000001.ply
    models_info.json
  train_pbr/000000/
    rgb/
    depth/
    mask/
    mask_visib/
    scene_camera.json
    scene_gt.json
    scene_gt_info.json
  sampling_manifest.jsonl
  run_summary.json
```

- 规范模型按 BOP 毫米单位写出，保持与 scene_gt 位姿相同的模型坐标系；原始输入文件不变。
- 默认 RGB JPEG、深度 PNG；深度缩放沿用原配置 `0.1`，在高级设置中可改并检查可表示范围。
- 分块大小、图像与掩码编号遵循 BOP writer 约定。只给目标写监督标注，遮挡物是场景干扰物。
- writer 自带的 COCO 附带输出可以保留，但不作为本项目的标签转换功能。
- manifest 记录实际 BOP 场景/帧号、区域 ID、相机位置与角度、HDRI、灯光、遮挡像素比和随机种子等。
- summary 包含请求、成功、跳过数量、失败原因统计和配置快照/标识。
- 新渲染任务默认使用新的输出目录；发现已有结果时拒绝覆盖并提示换目录。第一版不提供自动清空、追加或断点续渲。
- 导出任务目录也不得静默覆盖已有任务；由用户选择新目录或明确替换已存在的导出文件。

## 10. 质量与验收

功能验收至少覆盖：

1. Ubuntu 22.04 桌面应用可启动；导入真实网格后可观察并检查尺寸，UI 不需要在 `bop` 中安装 Qt。
2. 编辑球坐标边界后示意更新；固定角度、跨 ±180°、极点、多个区域的真实采样均满足定义。
3. 配置保存/载入后资源、单位、区域和参数一致，导出的任务可脱离 UI 运行。
4. 使用少量可控网格和 HDRI 在本机 BlenderProc 中完成实际试渲染，核验 RGB/depth/mask/pose 一致和 BOP 文件结构。
5. 固定方向任务的实际机位位于指定区域，输出的目标模型和 BOP 位姿使用一致坐标与单位。
6. 对可控遮挡场景核验实际遮挡率；无法满足时有重试上限、未完成记录和清楚的终端结果。
7. 已存在输出不会被删除，缺失依赖在渲染前明确指出，不发生隐式安装。

采样数学、配置恢复、导出可独立性和 BOP 单位转换使用针对性自动检查；UI 主题做人工视觉检查，不编写只重复布局实现的测试。实际渲染能否完成必须单独报告，不能用静态语法检查代替。

## 11. 留给实施者的决定

- Qt/OpenGL 视图库、依赖版本、源码模块组织和高面数网格的预览优化。
- 不改变配置语义的缓存、批处理、分割状态恢复和采样提速方法。
- 遮挡物候选生成和碰撞检测的具体算法，但需满足像素验收与重试约束。
- 默认点光源位置、缺省材质和三维观察视角的细节。
- 具体的参数错误提示、文件选择器细节和标准 Qt 键盘操作。
